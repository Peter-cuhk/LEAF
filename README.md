# LEAF project page

Static project page for **LEAF: Do Agent-as-Policy Robots Notice and Fix Their Own Failures?** (Learning From Failure Benchmark), served with GitHub Pages from the repository root.

- `index.html`: the whole page (no build step).
- `static/img`: figures from the paper.
- `static/video`, `static/poster`: simulation rollouts (GPT-6 Astra in Codex, retained history); `static/videos.js` lists them with per-attempt verdicts.
